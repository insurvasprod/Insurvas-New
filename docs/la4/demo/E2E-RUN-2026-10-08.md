## Findings from the run

**Fixed and committed (`10b37e2`):**
1. **4.13, the first-draft trigger:** a policy already paid past its effective date when first seen took a later paid-to change as its first draft. Its commission then looked due later than it was.
   - **Fixed:** the trigger is now the first file that showed the policy.
   - **The demo's 8 expected rows were priced before the fix.** A priced row is never rewritten, by design, so on the demo they read "first draft Oct 5 · due by Oct 26" (should be Sep 5 / Sep 26). DEMO-1008 therefore shows as due, not yet "missing".
2. **4.20, discrepancy lines:** a discrepancy's ledger lines and their row links never showed (a query that failed silently). Fixed.
3. **4.10, advances at risk:** Import your book's "Advances at risk" was hard-coded "Unknown". It now sums the ledger: $1,355.18 on the demo.
4. **4.14, wording:** "1 policies" now reads "1 policy".

5. **4.7 / 4.12, advance rules keyed by the wrong product code (fixed later the same day, `df540de`, migration `20261008300000`):** "Inside the clawback window" and the ledger's advance rule looked advance rules up by the carrier's own product code ("FE Level"), but advance rules are keyed by our product family ("final_expense").
   - **Fixed:** both now go through the carrier → product-family mapping (`carrier_product_family`).
   - **On the demo now:** all 8 policies are inside the clawback window. DEMO-1003 reads **"Chargeback coming" −$233.40** (Coming back $233.40), so Discrepancies has **2 open**. On Policies, DEMO-1005 and DEMO-1006 now read **Critical** (at risk inside the window).

Earlier today, also committed: the faster matching on status-approval reprocessing (`db7fac5`), and the call-list wording fixes (`3e46b62`, `1f78231`).

**Open, not fixed:**
6. **Staff screens can't version an agency's own layout map:** they list platform maps only. The demo's v2 was published through the database function.
7. **Narrow screens:** below about 800 px, a long carrier name in a filter overlaps the Export CSV button (Commission ledger).
