Get set up · what the built page gets wrong

  1. Once it's done it says nothing. A finished agency sees a wall of green ticks and "All done" in the corner: no sense of progress, nothing to show a client.
  2. It uses a third of the screen. Rows run the full width with the action 1,700px away from the label; the bottom half is empty.
  3. Every step looks the same. A 5-minute required step and an optional review have the same weight; you can't see what a step is or how it's done without leaving the page.
  4. Docs is a row at the bottom, though every step has its own Docs page and video.
