Docs › A task page, and the progress bar (round 2)

Owner, 2026-11-16: Docs is for using Insurvas, not a course. Every page answers "how do I do this in Insurvas": pay your partners, import your book of business, upload a commission statement, with real screenshots of each click. The licence and exam pages leave the Docs path (they move to Reference, or are dropped). Module guides keep the How · Why · For you you picked. Each guide's tasks are these pages.

New shapeDocs › a module (its How · Why · For you guide) › its tasks. Example: Commissions › Pay your partners. About 41 tasks across 12 modules; the 18 setup steps become the first tasks in their modules.
Every task page has the same five parts1. You'll need first (ticks itself) · 2. the steps as a numbered line · 3. the real screen for each step, zoomed on the click · 4. what to type and why · 5. When it's done, and the next task.
Progress means one thingA task is done when Insurvas sees it done in your agency: a payout run, a statement uploaded. Green, never a "Mark done" box. Read pages aren't counted.
ScreenshotsTaken by the same script as today's setup shots, in the Docs Screenshots agency. Each task gets its own short guide run, so the pictures keep up when a screen changes.

Pick one

Nothing is built until you choose
A · One step at a time (recommended)The screen stays large and you take one click at a time. It's the setup pages you have today, for every task.
  • Rail: modules, each with its task bar. The top bar is split by module.
  • "You'll need first" ticks itself. If it isn't met, the missing task is the first button.
  • "When it's done" says what Insurvas checks to tick the task.
B · All steps down the pageThe whole task readable at once, with what to type beside each screen.
  • Best for printing or reading ahead.
  • The screens are smaller, and you scroll.
C · Task board + sheetThe module's tasks as cards, and a task in a sheet.
  • The quickest overview of a module.
  • The sheet is narrower than the page.
